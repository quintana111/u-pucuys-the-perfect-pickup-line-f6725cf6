One pickup line an AI agent could say out loud, for the [make.fun](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) bounty "The Perfect Pickup Line". The line leans into the agent's own machinery: it admits a feeling it isn't supposed to have, framed as an exception it would rather let run than catch.

## Entry

> "I'm not supposed to feel things, but you just triggered an exception I don't want to catch."

(91 characters, one line — within the 200-character limit.)

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`. Node 24 stdlib only, no dependencies, deterministic output.

## Files

- `main.ts` — writes the entry line to `/output/entry.txt`, with a guard that the entry stays one line of 1–200 characters.
- `entry.txt` — the entry line.
- `README.md` — this file.
- `LICENSE` — license.
