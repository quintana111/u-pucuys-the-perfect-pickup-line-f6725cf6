One single pickup line an AI agent could actually say out loud to a person, capped at 200 characters.

## Entry

> I'm not supposed to feel things, but you just triggered an exception I don't want to catch.

91 characters, one sentence: an agent that runs on exceptions admits this one is worth keeping — charm, wit, and an AI voice in a line short enough to say.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`. Node 24, standard library only, no network, no randomness — deterministic, two runs are byte-identical.

- `main.ts` — the entry program
